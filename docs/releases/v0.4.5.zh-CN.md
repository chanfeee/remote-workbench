# Remote Workbench v0.4.5

[English release notes](v0.4.5.md)

本地 Agent 与 MCP 控制端，远端命令和文件操作，本地可回看的操作记录。
本版汇总 v0.4.0 之后的更新，作为已验收的稳定发行。

## 主要变化

- 直接使用选定的已有远程目录，支持非 Git 的 build/run 目录，不复制工程，
  不在远端运行 Codex CLI。
- 支持 shell、argv、stdin 和本地同款补丁；可合并选定文件读取、修改和检查，
  保留完整输出及受管 diff。
- 多聊天可以共享目录。受管编辑按文件协调，普通命令和后台任务不再占用整个目录。
- 在聊天中显示紧凑的命令、输出和可展开的彩色 diff。每次操作使用独立卡片标识，
  后续操作不会替换之前的卡片；收起内容后不再留下大块空白。
- 保持 8 项会话工具。卡片预览使用 UI 专用元数据，不重复写入模型可见正文，
  不增加模型调用；正常的工具参数和输出仍属于聊天上下文。
- 默认直接依赖保留 MCP/PyYAML；Web/PTY 和 SSH 网关分别按需安装 `web`、
  `proxy` 扩展。费用测试和历史测试证据工具移至源码中的离线辅助目录。

继续使用人工 SSH 认证和已有 OpenSSH ControlMaster。新聊天默认本地，远端失败
不自动改为本地执行；原任务恢复、取消、超时、文件冲突保护和本地 CLI 记录查询保留。

## 验收结果

- 运行时代码通过 869 项本地测试，无跳过；wheel、源码包及已安装 MCP 启动检查通过。
  分支 CI 覆盖 Python 3.10—3.13，发行工作流会再次测试并构建固定的 tag 提交。
- 实际 App 已加载 stable 0.4.5。用户切换聊天再返回后，确认两张命令卡片保留；
  随后单独测试并确认两张 diff 卡片均保留，逐行差异可以展开查看。
- 既有目标、任务原始位置和本地历史保留。服务器细节、测试材料、用量报告及宿主
  私有代码片段不进入源码或发行附件。

## 安装与更新

在本地控制端下载本次 Release 的 wheel 和 `runtime-requirements.txt`，然后运行：

```sh
python -m pip install --constraint runtime-requirements.txt ./remote_workbench-0.4.5-py3-none-any.whl
```

需要图片/PDF/SVG 预览时，显式选择本地 wheel 的 `images` 扩展：

```sh
python -m pip install --constraint runtime-requirements.txt './remote_workbench-0.4.5-py3-none-any.whl[images]'
```

选择明确的服务器和目录，复用人工建立的 SSH 连接。替换旧安装后重载 MCP；App
启停开关仍由用户控制。附件包括 wheel、源码包、锁定依赖约束和 `SHA256SUMS`；
源码包另外包含离线 benchmark 工具。

## 兼容范围

已有记录仍可读取；缺少独立标识的旧聊天卡片不会被改写。本次未验收完整 App
重启及 UI 输出分页，不宣称整个 Agent 的耗时/token 已接近本地。
文件协调针对受管编辑，不覆盖外部终端或任意 shell 内部的所有写入。
