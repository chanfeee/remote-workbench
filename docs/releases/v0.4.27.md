# Remote Workbench v0.4.27

[中文说明](https://github.com/chanfeee/remote-workbench/blob/v0.4.27/docs/releases/v0.4.27.zh-CN.md)

- Call `workspace_info` directly to read the current chat's workspace binding and the loaded MCP version from local state. The tool advertises a read-only annotation, which Codex uses to skip approval in `writes` mode.
- This release includes the stable updates since v0.4.5. Read-only probes return compact text. Managed edits show every changed file in an inline diff and report file verification and any requested post-edit checks.

The release workflow tests the tagged stable commit. Its assets include the wheel, source distribution, locked runtime constraints, and `SHA256SUMS`.

Download the wheel and `runtime-requirements.txt`, then install them on the local control machine and reload the MCP server.

```sh
python -m pip install --constraint runtime-requirements.txt ./remote_workbench-0.4.27-py3-none-any.whl
```
