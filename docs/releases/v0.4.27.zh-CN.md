# Remote Workbench v0.4.27

[English release notes](v0.4.27.md)

- 可直接调用 `workspace_info`，从本地状态查询当前聊天的工作区绑定和已加载的 MCP 版本。该工具带只读标注，Codex 在 `writes` 模式下可跳过审批。
- 本版包含 v0.4.5 之后的稳定更新。普通只读探测返回精简文本。受管修改在内联 diff 中列出所有变更文件，并报告文件验证和指定的修改后检查结果。

发行工作流会测试 stable 上的固定标签提交。发行附件包括 wheel、源码包、锁定的运行时依赖约束和 `SHA256SUMS`。

下载 wheel 和 `runtime-requirements.txt`，在本地控制端安装，然后重载 MCP 服务。

```sh
python -m pip install --constraint runtime-requirements.txt ./remote_workbench-0.4.27-py3-none-any.whl
```
