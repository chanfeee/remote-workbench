# Remote Workbench 开发任务拆分

初始拆分日期：2026-10-25。初始核对基线：`develop` 提交 `bebcbea1427c39f46f6f2fcb579a33f72c6b2797`，版本 `0.3.0a11`。

**2026-10-26 范围更新**：当前 develop 阶段基线为提交 `ae380a9`（a13）。本轮只推进阶段1：MCP 记录明确目标上的命令、文件和后台生命周期事实；科研解释、验证是否充分及被操作项目的测试适用性由调用 Agent 和用户判断。`workspace_resume()` 默认只返回 binding/jobs/note 操作事实；显式读取旧测试历史时为只读，且不推断其当前适用性或触发 SSH 扫描。`workspace_snapshot()` 默认检查显式元数据与 Git 状态，只有显式启用有界内容扫描才计算指纹，不自动维护项目验证结论。Token/credits 计量仅用于手动运行的独立、可重复基准样本；Remote Workbench 自身的日常命令、编辑和测试路径不采集 token/credits 或模型费用，不因计量增加模型调用；日常工作流不在回复或 UI 中追加用量评估，也不以基准门槛阻止普通任务完成。此约定仅限 Remote Workbench 自身的执行与集成路径，不声明 Codex App 或模型服务如何记录账户用量。费用账本和脚本保留为测试辅助工具；完整操作记录与必要执行诊断照常保留。功能正确性、develop CI 与 stable 发布规则仍是各自的验收要求。

本文将用户建议拆成可验证的工作包。状态仅表示本轮核对结果；“已复现”不表示已修复。每个实现任务单独提交，按依赖集成，不把六个方向合成一个大重构。

## 决策与边界

- 本地保留 Agent 控制、聊天工作区、任务归属与审计；用户显式选择远端执行目标。普通本地任务仍使用原生本地工具，不自动进入远端。
- 聊天身份、仓库来源、实际工作目录分别建模。未来支持不同仓库、同仓独立目录和显式共享同一实际目录。
- direct 尚未实现；当前默认仍是 copy。先完成显式 direct/copy 与所需协调并通过单独验收，再独立切换新建目标默认值。已有 copy 目标保留原路径、任务和记录，不自动改绑或清理。
- 保留人工认证、Agent 复用现有 ControlMaster 的流程。失去可用连接时明确失败，不自动重新认证。目录限制和 skill 都不等于操作系统沙箱。
- 保留完整功能、编辑保护、审阅、作业停止和恢复能力。MCP 记录可核验的操作事实；测试结论及其对项目是否适用由调用 Agent 和用户判断。compact 有界摘要保留，subTest 计数不确定时继续报告未知。
- Token/credits 计量限于手动运行的独立、可重复基准。Remote Workbench 自身的日常执行路径不采集用量或费用、不添加计量模型调用，也不在日常回复/UI追加用量评估；此约定不涵盖 Codex App 或模型服务的账户用量记录，也不阻塞普通任务完成。2% token 阈值与历史样本的口径和记录见[独立 Token 基准](token-budget.zh-CN.md)，不解释为费用百分比。
- 最初拆分完成本地最小复现；第一批现已由有文件边界的子 Agent 执行并经父级审阅、集成回归。远端目录默认值、全局安装入口和 stable 均未改变。

优先级：P0 为会误导结论、阻塞基本流程或影响后续目录行为的前置项；P1 为日常可靠性与迁移；P2 为有基线后再验证的扩展。下列交付物都是具体提交范围，不意味着当前已实现。

## 依赖与实施批次

1. **阶段1（当前）：操作事实与后台生命周期。** MCP 记录明确目标上的命令、文件、job 和 note；默认恢复不读写测试缓存，旧测试历史只在显式选项下只读。快照默认是元数据/Git 检查，内容指纹需显式启用有界扫描。本轮仅实现此阶段；D3 自动测试管理已退出默认范围，compact 有界摘要及 subTest 未知计数边界保留。
2. **后续：direct/copy。** 按 A1/A2 契约实现显式模式、兼容迁移和第一版协调；direct 目前尚未实现，默认 copy 与已有 copy target 不变。新建目标默认切换是 direct 显式验收后的独立变更。
3. **随后：通用 C2/C3。** 继续完善任何后台作业的恢复、采集、取消和 unknown 生命周期；不依赖 D3 测试尝试或适用性管理。
4. **随后：copy F1/F2。** 修复 copy 符号链接状态与重复交付确认，保留 copy 的 baseline、交付和冲突保护。
5. **之后：只读 HTML/CLI（D4/D5）。** 展示操作事实、日志和有界摘要；不执行项目验证或写操作。E2/E3 仍是按需独立实验，不改变普通任务的完成条件。
