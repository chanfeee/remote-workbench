# 原目录与独立路径工作流的自动化验证

本地待发布开发代码统一使用实际目录，不支持工程副本模式或旧副本恢复。公开记录仅描述通用行为及本地模拟测试，不包含个人服务器或实机操作流程。

`tests/test_original_directory_workflow.py` 覆盖：

- 不依赖 Git 的已有目录执行；代码、环境、运行和结果路径独立指定，不生成工程副本，环境不跨调用继承。
- 拒绝受管副本路径及其符号链接，监督器检查物理 cwd，拒绝后不执行用户命令。
- 固定入口共享原目录代码，记录和运行状态独立，共享审计根下协调受管写入。
- copy 参数、交付和预览接口不可用，校验错误不连接 SSH。
- 旧副本绑定及任务不接回，返回拒绝或未知原因；旧文件、任务归属和本地记录不删除、不迁移。

```sh
python -m pytest -q tests/test_original_directory_workflow.py
```

原目录后台任务的丢失回复、重启、切换目标和连续日志恢复由 `tests/test_mcp_job_recovery_stdio.py` 验证。受管编辑冲突、共享目录协调和超时/取消由对应定向测试覆盖。

本轮移除了副本准备与交付模块及其专属测试；通用生命周期测试改为实际目录语义，显式有界指纹测试保留。旧验收报告中的副本行为是历史事实，不再代表当前接口。

新行为需要重载所有相关 MCP 实例；独立 stable 未变。本地模拟通过不等于真实 CERN/IHEP 或 App 已加载版本验收。最终回归和构建结果见 [验证记录](../../VALIDATION.md)。
