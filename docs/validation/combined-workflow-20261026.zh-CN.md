# 组合接口的自动化验证

本文件记录可移植的接口行为和本地自动化测试。个人服务器操作流程、节点、代码目录、聊天、费用及原始操作记录不进入仓库。

## 覆盖范围

`tests/test_combined_workflow.py` 使用临时工程和本地模拟传输，覆盖：

- 显式绑定、初始命令和指定文件读取共用一次调用；只为指定编辑文件创建快照。
- 补丁成功后执行调用者明确指定的命令，沿用原绑定和写入占用。
- 成功修改返回新的编辑引用；后续命令或外部修改仍会使旧哈希失效。
- 补丁冲突时跳过命令，预览与命令不能混用，认证和计算审核在修改前执行。
- 修改成功与命令退出失败分别返回；命令状态未知时保留资源冲突。
- 并发目标切换不能把后续命令带到新目录。
- 补丁、命令工具记录和实际传输记录通过父子关系关联。

该测试文件共15项通过；集成完整本地回归为689项通过。完整回归曾发现嵌套审计链缺失中间层，修复后完成定向及完整复验。测试数表示对应集成时点，不是永久固定的项目测试总数。

2026-10-27 补充一个完整小工程用例：首次只绑定并取得记录链接，同目标检查并读取要求／两个源码快照，再一次修改并返回测试、空白检查、完整 Git diff 和新编辑引用。该用例使用三次 MCP 操作，不需要再读源码或另取审阅输出；工程、Git 索引和 worker 均在临时本地目录中。它验证接口能提供完整材料，没有运行模型，不能将三次操作报告成实测模型回合数。

```sh
python -m pytest -q tests/test_combined_workflow.py
```

## 保证边界

组合参数是显式执行接口，不是通用任务编排或自动项目验证。补丁与命令不是回滚事务，命令失败不代表修改已撤销。目录占用仅协调共享本地状态的受管操作，不能限制外部终端或其他控制端。

本地模拟和构建结果不代表任意真实服务器或客户端已完成部署验收。实机与客户端验收由使用方按自己的环境进行，原始记录保存在仓库之外或被忽略的本地运行目录。

组合调用减少了客户端必须往返的接口边界，但不能约束模型的请求次数、代码生成和额外查询。实际token差额只能通过独立完整任务样本测量，不能由接口数量、响应字节或自动化测试通过推断。
